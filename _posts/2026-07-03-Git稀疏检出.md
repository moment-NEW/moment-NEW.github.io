# 前言
折腾的时候发现稀疏检出都没个很好的方案，AI自己都搞不明白。最终选了一套最可靠的：这里以Pigweed为例子


# 1. 创建目录并初始化 git 仓库
mkdir pw_tokenizer
cd pw_tokenizer
git init

# 2. 添加远端
git remote add origin https://github.com/pigweed-project/pigweed.git

# 3. 开启稀疏检出
git sparse-checkout init

# 4. 设置只检出的目录（可以是多个）
git sparse-checkout set pw_tokenizer

# 5. 浅层拉取（只取最新 commit，不下载不需要的 blob）
git fetch --filter=blob:none --depth=1 origin main

# 6. 检出
git checkout origin/main
