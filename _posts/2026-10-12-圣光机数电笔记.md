# 数字信号
模拟信号：连续信号，有无穷个值。
数字信号：离散信号，有限个值，（通常来说）使用1和0两种逻辑值。比如以5v为逻辑1,0v为逻辑0
这个电压是随意的，例如5V VCC,3.3V VCC，Vout表示输出高电平，Vin表示输入高电平。对于一些零件来说，也可能会有高电压输入低电压输出的情况，这是为了抑制噪声的考虑或各种环境因素的损耗影响。  
| 符号 | 含义 |
| --- | --- |
| VCC | 电源电压（供电），比如 5V 系列就是 5.0V，3.3V 系列就是 3.3V |
| VOH | 输出高电平：芯片输出"1"时，最差情况下引脚上至少有这么高的电压 |
| VOL | 输出低电平：芯片输出"0"时，最差情况下引脚上至多这么高 |
| VIH | 输入判高门限：输入电压高于它，接收方才保证当成"1" |
| VIL | 输入判低门限：输入电压低于它，才保证当成"0" |
| VT | 翻转阈值（threshold），实际比较器翻转点，介于 VIL 和 VIH 之间 |
也正是环境的影响，数字信号的上升沿和下降沿都不一定是垂直的，由于电路中的电容和电感，基本上不可能出现理想的数字信号形式。
通常来说，上升沿被称为正沿，下降沿称为负沿，后续我们将继续使用这两个术语。
# 组合逻辑
组合逻辑：输出由输入信号的组合决定。  
例如，在算术逻辑单元（ALU）中，如果我们将 2 放入输入 A，将 3 放入输入 B，ALU 进行加法运算，我们将“立即”在输出 Y 得到 5。得到结果的时间仅与信号通过电路所需的时间有关。如果我们将输入值改为 1 和 5，我们将在输出中得到 6。这就是组合逻辑，我们改变输入，立刻得到结果。  
另外一个概念是时序逻辑。    
输出由输入信号和先前状态的组合决定。这意味着它是一种具有记忆功能的电路。例如，寄存器、计数器、移位寄存器都基于时序逻辑。这种逻辑可以存储先前的状态，常用于寄存器。
## 时钟信号
时钟信号用于时序逻辑的同步，由于使用多个时钟信号会出现亚稳态等问题，因此课程中尽量只用一个时钟信号。  
例如，假设我们有两个 D 触发器（每个触发器存储 1 位数据），需要将一个信号从一个 D 触发器传输到另一个 D 触发器。如果这两个触发器使用不同的时钟信号，则无法进行传输。两个触发器必须通过一个时钟信号的上升沿或下降沿进行同步。在这种情况下，我们可以使用时钟信号上的某个事件，将一位信息存储在第一个或第二个 D 触发器中  
所有时钟信号都存在不确定性。这意味着时钟信号的周期可能会有很小的偏差，因此 T1（第一个周期）不会等于 T2（第二个周期）。不确定性的大小与时钟质量相关：不确定性越小，时钟质量越好。   
# 如何表述？
下一个问题是我们如何表达我们的电路方案。
我们可以使用图片，也可以使用文本（或代码）。使用图片，我们可以直观地看到方案的功能实现方式，而文本表示则提供了功能方面的信息。图片适用于小型方案，而文本表示适用于大型方案。目前有两种流行的硬件描述语言（HDL）：VHDL 和 Verilog HDL。  
HDL 帮助我们用简单的方程来描述复杂的方案。它可以描述硬件电路的结构和行为。

## 晶体管电路
现代方案中晶体管一般使用CMOS技术（互补金属氧化物半导体）。这种设计基于两种晶体管，n MOS和p MOS，虽然这是两种晶体管，但是我们的学习不需要了解其基本物理特性和原理，只需要理解为一种抽象的元件就行——互补的意思就是有两种不同工作方式的晶体管，MOS意味着我们使用半导体衬底（金属M-氧化物O-S半导体），以及半导体组成的n沟道和p沟道。它具有称之为源极，栅极，漏极的金属电极，栅极之间以二氧化硅作为材料。
栅极是控制源极和漏极之间电流流动的关键电极。 
- 对于n-MOS:

你可以看到一个 n 沟道 MOS 晶体管。它可以导通，也可以关断。栅极触点就像一把钥匙：它控制晶体管的导通或关断状态。当栅极信号为逻辑 0 时，钥匙断开（无电流）；当栅极信号为逻辑 1 时，钥匙关断（有电流）。这就是晶体管的“钥匙模式（key mode）”。  
如果我们把栅极设置为逻辑0，然后源极接地，那电流将无法流动，钥匙会打开（开路），但如果栅极和源极的电压大于0，则漏极和源极之间会有电流流动。  
- 接下来讨论p-MOS：
它的工作方式与 n-MOS 晶体管不同。源极需要连接到电压源。如果我们将栅极电压设置为逻辑 1，晶体管将导通（没有电流通过）。但如果我们将栅极电压设置为逻辑 0，则源极到漏极之间会有电流通过，晶体管将导通

## 基本功能模块

### 多路复用器、解复用器
多路复用器是一种数据选择器。多路复用器是一种组合逻辑网络，它从多个可能的输入信号中选择一个，并将该信号导向单个输出端。特定输入的选择由一组选择变量控制。一个具有 n 个选择变量的多路复用器通常可以从 2^n 个输入信号中选择一个。  
在电路图中，它可以表示为一个具有 2 位地址、4 位输入和 1 位输出的块。  

解复用器（或数据分配器）与复用器正好相反。它接收单个数据输入，并将其路由到多个可能的输出之一。它是具有 2 位地址、1 个输入和 4 位输出的模块。
### 译码器
下一个基本功能模块是译码器。您可以在幻灯片中看到，它有一个输入代码和一个输出代码。这里我们看到的是一个位置译码器。这意味着我们以位置作为输入，并在相应的输出中得到逻辑 1。例如，输入 010 会将 Q2 设置为 1，而输入 110 会将 Q6 设置为 1。译码器可以有很多种，这里展示的只是其中一种。  

编码是将一组输入形成编码表示的过程，它是译码操作的逆过程。编码器是一种组合网络，它生成一个 n 位二进制代码，该代码唯一标识 m 个激活输入中的一个（0 ≤ m ≤ 2− 1）。
编码器的功能与解码器相反：它将位置编码转换为二进制编码。幻灯片中展示的是一个位置编码器。同样的，编码器还有其他类型。
### 算数模块
下一类模块是算术模块。它们可以用逻辑门构建。在电路图中，我们将算术模块称为 ALU 模块。ALU 的符号表示输入 A 和 B、一些操作码输入、输出以及对输出执行的操作符号。它可以执行加法、乘法等运算。

最后一个基本模块是计数器。你可以从图中看到它的工作原理：每个时钟周期，计数器改变 Q0 的输出值；每两个时钟周期改变 Q1 的输出值；每四个时钟周期改变 Q2 的输出值。因此，每个输出都会产生一个频率比前一个输出低两倍的方波信号。

微架构主要可以分为两部分：数据流和控制流
## 数据流
描述数据如何从一个模块到另外一个模块，影响计算性能。
## 控制流
描述各个功能单元中操作的执行方式，控制单元负责实现与数据流处理相关的算法。

如果我们再来看看简单的单周期 MIPS 处理器的微架构图，就会发现：控制流相关的模块和连接被标为蓝色，而数据流相关的模块和连接则被标为黑色。在开发项目时，必须明确区分这些控制流和数据流部分。如果将控制流和数据流相关的模块混在一起，虽然该架构在当前可能还能使用，但将来很难进行扩展和进一步开发。这样的架构也难以理解。为了使设计更易于理解，最好将微架构分为两个主要部分：控制流和数据流。因此，在设计时，应分别绘制这两个部分。控制流通常由控制单元构成（例如，可以由微程序控制单元或有限状态机来实现），此外还包括一些控制相关的组件

# 时钟域交叉技术（CDC）
有几种技术可以避免这种情况，但它们相当复杂，所以最好使用一个时钟信号来同步方案中的所有设备。


避免电路中出现亚稳态信号的第一种方法是使用两个触发器而不是一个。这种方法称为双触发器同步器。其中，第一个触发器处于亚稳态，从而降低了第二个触发器输出端出现亚稳态的可能性。   

另一种技术采用所谓的“握手”方法。它使用两个信号：请求信号和确认信号。如果源控制和目标控制使用不同的时钟，则需要使用请求信号和确认信号，并通过两个触发器同步器来避免方案中的亚稳态信号。该方案的工作原理如下：如果源设备想要发送数据，它会生成请求信号。目标设备生成确认信号作为响应，然后源设备可以将数据发送到目标设备。在我们的实验中，为了避免此类问题，我们将只使用一个时钟信号。  


我们在此总结了几条钟表设计规则：
1. 当信号从一个时钟域传输到另一个时钟域时，需要消除两个时钟域之间的组合逻辑路径。这需要插入寄存器。

CLB是由查找表LUT和触发器FF组成的。CLB可用于实现组合逻辑电路和时序逻辑电路（前面提到过的）。对于组合逻辑电路可用LUT,后者可用CLB。它通过组合两种资源实现各种各样的逻辑。  
LUT（Look-Up Table，查找表）的本质是一块极小的 1 位存储器 + 地址译码器。

原理：任何布尔函数都可以用真值表完整描述。以图中 4 输入 LUT 为例——4 个输入有 2⁴ = 16 种组合，每种组合对应一个确定的输出值。那干脆把这 16 个输出值预先存进 16 个 SRAM 单元里，把 A₁~A₄ 四根输入线当成 4 位地址送进去，地址译码后选中对应的单元，“读”出来的值就是函数输出。

比如要实现 F = A₁·A₂ + A₃·A₄，工具软件会把 16 种输入组合下的正确结果算出来，在配置时写进这 16 个存储位。之后不管来什么输入，查表就是答案——不搭任何门电路，用存储代替运算。图中 LUT 下面那个小方框，就是保存这 16 位配置数据的配置单元。  


这也是 COA 里讲过的思想：任何组合函数都能用 ROM 实现，LUT 就是把这个思路做到极致、做成可重写的小 ROM。  

LUT 只能做组合逻辑：输出只取决于当前输入，断电即忘，没有状态。但计数器、状态机、寄存器这类时序逻辑必须记住“上一拍是什么”。  

FF（Flip-Flop，触发器）就是边缘触发的 D 触发器：在 CLK 时钟上升沿，把 D 端的值锁存进 Q，其余时间 Q 保持不变。图里每个 LUT 配一个 FF，还带 R（复位）、S（置位）控制线，用来异步清零或置一。  

简单来说，就是你可以通过模拟真值表的行为来模拟任何一种组合逻辑电路。

### 费林处理器分类法
根据指令数据的不同，处理器又有以下分类：



SISD（单指令单数据流，单核处理器）。例如，我们有一个处理器、一个数据存储器和一个指令存储器。我们可以使用一个处理核心来执行一些数据相加操作。

单指令多数据流（SIMD）（GPU、Intel SIMD 扩展）。例如，我们可以在这里将多个值相乘，为此可以使用多个处理器单元。这些处理器单元可以是 GPU 或向量协处理器。这种结构可用于数学运算，例如向量乘法。

MISD 多指令单数据（脉动阵列等）意味着我们有不同的结构对应一种数据。

这种架构使用单条指令处理同一组数据，例如，在某些数字信号处理中，我们需要对同一组数据执行多个操作。数据从一个处理器单元定向到另一个处理器单元。这种架构常用于脉动阵列。

MIMD（多指令多数据流，并行计算机）。所有处理器单元都是独立的，可以处理各自的数据并执行各自的指令。这种处理器用于并行计算机。  
## 硬件加速器
我们常听到FPGA和ASIC加速了各种东西，这就是所谓的硬件加速器。

硬件加速器可以通过多种方式集成到电路中：

第一种方法是开发自定义指令。



处理器架构可以通过硬件加速器实现的自定义指令进行扩展。例如，如果某个处理器只能实现加法、减法、移位运算和逻辑运算，我们可以添加一些自定义运算，例如除法、乘法、幂运算或对数计算等等。我们可以设计一些硬件加速器来实现这些自定义指令，并将它们添加到计算机的指令集中。



所有自定义指令都有类似的结构：它们最多包含两个数据输入和一个数据输出，以及可选的时钟、复位、模式、地址和状态信号，以便进行更复杂的多周期操作，从而了解何时可以获得结果。



自定义指令是一种阻塞操作，它会阻止处理器执行其他指令，直到自定义指令完成。虽然这会降低性能，但自定义指令的执行时间通常很短，因此对整体性能的影响不会非常显著。这种做法通常又叫做协处理器。

### GPU
耳熟能详的GPU实际上是一种图形硬件加速器。
多核 CPU 包含多个核心，但每个核心都是一个复杂的设备，根据特定的程序运行。GPU 则是一种 SIMD 设备。GPU 由数百个核心组成，但每个核心的结构比 CPU 核心的结构简单得多。GPU 核心可以执行诸如加法或乘法等简单运算。每个现代 GPU 都包含多个流式多处理器（SM）。幻灯片中展示了 GPU 的结构。每个流式多处理器中包含多个核心。它不仅可以用于图形处理，还可以用于处理通用数据，例如科学计算、处理大型数组或大数据等等。  

典型的编程流程如图所示。在一个处理器（红色）中，我们使用顺序执行；而在 GPU 中，并行执行是通过单指令实现的。首先，我们需要将数据从主内存复制到 GPU 内存。然后，我们需要将配置信息发送给 GPU，之后开始处理：数据将由多个核心并行处理，最后，我们需要将结果复制到主内存。

### npu


现在我们将简要讨论可作为基于神经网络的硬件加速器的神经网络处理器。

第一种架构类型是流水线架构。它具有全局内存，以及分别用于存储输入数据和输出数据的局部内存块（MemRD 和 MemWR）。输入数据从全局内存传输到输入局部内存，然后在网络的不同层执行一些计算（例如卷积、池化等）。计算结果存储在输出局部内存中，然后被复制回全局内存。

# HDL
Datapath（数据通路）就是数字系统里“数据实际流过、被加工”的那部分硬件：寄存器、ALU、加法器、移位器、多路选择器（mux）、连接它们的总线。它只负责搬运和运算，不负责决定“什么时候、按什么顺序做”。

与之相对的是 controller（控制器），通常是一个有限状态机（FSM），根据当前状态和状态标志产生控制信号去指挥 datapath：mux 选哪条分支、ALU 做哪种运算、哪个寄存器使能写入。

HDL 教材反复强调这个划分，因为它是 RTL 设计的标准方法论：先把要实现的功能映射成一个由寄存器和运算单元组成的 datapath 结构，再单独写一个 FSM 驱动它，顶层把两者 instantiate 到一起。这种结构有个名字叫 FSMD（FSM with Datapath）。

Systolic array（脉动阵列）是由大量相同的小处理单元（PE）排成规则网格、数据像脉搏一样周期性“泵”过阵列的并行计算结构。 这个词是 H.T. Kung 和 Leiserson 在 1978 年造的，取自医学术语“心脏收缩期”（systole）：外部存储器扮演心脏，把数据有节奏地泵进阵列，每个 PE 用一次手头的数据再传给邻居——同份数据沿途被反复利用，而不是每个运算都回存储器取一遍。

单个PE通常就是上述的DATAPATH写法：

算矩阵乘法 C = A×B 时，每个单元固定存一个权重 w[k][j]（所以叫 weight-stationary，权重静止），激活值 a[i][k] 沿行从左往右流，部分和沿列从上往下流，一个周期每个单元恰好做一次乘加。输入按对角线错拍（skewed）送入，保证正确的 a 和正确的部分和恰好在同一拍相遇；进入稳态后每个周期从阵列底部流出一个结果。阵列整体像一个二维流水线，数据以“波前”形式扫过。

它高效的原因有三条，全都直接来自结构：

数据复用：一个操作数从存储器取出一次，在流过阵列的途中被 N 个 PE 使用，计算/访存比是 O(N)——这正是针对冯·诺依曼瓶颈（访存跟不上计算）设计的。
局部互连：PE 只连上下左右，没有长导线和全局总线，布线短，时钟频率高，天然适合 VLSI/FPGA。
极致规则：只设计一个 PE，然后用 HDL 的 generate 循环平铺 N×N 份，几行代码综合出几万个乘加器。

# IO外设架构
io外设由data 寄存器，status/control寄存器，IO logic，还有若干external interface logic组成。
相对于的，外设有一个control logic和一个buffer寄存器。

cpu和外设的交互是通过总线的，这里计组讲过了。根据交互的方式不同可以分为同步类型和异步类型：
对于同步：
- 每个处理器的请求都会在设备中立即得到处理。
- 处理器能够判断出设备何时处于可用状态。
- 同步意味着外围设备始终处于可与处理器进行数据交换的状态。

对于异步；
- 处理器应定期检查设备的状态，以确定设备何时可以正常使用。  
- 处理器无法判断设备何时已准备好使用。  
- 异步意味着，当处理器需要与外设进行数据交换时，该外设可能尚未准备好进行数据交换。  


– 在计算机系统中，大多数通信都是异步进行的。

用于实现异步通信的各种 I/O 技术如下：
– **程序化 I/O**：处理器通过软件来完全控制数据的交换过程。
– **中断驱动 I/O**：当外设准备好进行数据交换时，会通过专门的硬件信号来通知处理器。
– **DMA（直接内存访问）**：外设与内存之间可以直接进行数据交换，无需处理器的干预或控制。

## HLS
即高级综合High-level Synthesis，指的是将设计的较高层次表达形式转换为较低层次的实现形式。具体来说，就是将各种算法转换为 Verilog 代码。在这里，我们将 C/C++算法或程序视为设计的高级表现形式。通过 HLS 工具，可以将 C/C++程序转换为硬件描述语言，也就是 Verilog 代码。 
## Synthesis

Synthesis合成——指的是将各个组成部分组合起来形成一个完整的系统。在我们的语境中，HLS 工具会使用各种功能模块，比如多路复用器、解码器、寄存器等等。HLS 工具能够把这些模块组合起来，从而形成一个完整的系统。
## Abstraction level
抽象层次——指的是在描述系统时省略那些不重要的细节后的层次。将算法层面的描述转换为硬件层面的微架构描述，实际上就是系统描述在不同抽象层次之间的转换。例如你可以把C转换为HDL，这个过程只需要一个HLS工具来辅助。

## 形式化
形式化指的是将数据以某种便于人类或机器存储、传输和处理的格式来表示的过程。例如，语言就是一种基本的形式化工具。
形式化的目的是实现自动化：增加可重用的元素。当我们用某种语言描述了某个算法后，就可以轻松地将其转换成另一种语言，比如 Verilog。
所谓***“高级综合”**，指的是在完全不需要人工干预的情况下，将某种抽象层次上的方案转换为另一种抽象层次上的方案。

## HLS stages
HLS分成若干阶段：



- 调度。也就是对各项操作进行时间上的安排。在这里，我们需要从算法中提取出各项操作，并确定它们各自应执行的时机，这就是所谓的调度操作。

- 资源分配。需要确定执行各项操作所需的资源。在规划好所有操作之后，我们必须为每项操作分配相应的资源。这一工作可以通过专门的软件或硬件来完成。就硬件实现而言，需要将每项算术运算与相应的硬件模块相对应起来（比如乘法器、加法器、除法器等）。这些分配工作可以在资源分配阶段完成。同时，还需要根据各项操作的实际需求来连接它们。最后，还需要提取出控制逻辑，并构建出控制单元。

- 控制逻辑的提取。需要构建用于控制数据流的逻辑结构。由于每个程序都包含大量的操作步骤，而这些操作步骤必须相互协调才能实现数据的正确传输，因此，我们需要为各个模块都设计相应的控制逻辑。

# HLS设计进阶
我们将探讨时间与面积的优化、功耗的优化，以及如何提高设计的可靠性——也就是说，如何提升数字电路的可靠性。  (什么废话)
## 优化指标
如果没有benchmark我们很难说是否改进了我们的设计。
要进行性能优化，需要了解三个关键性能指标。它们分别是吞吐量Thoughput、延迟Latency和本地数据路径延迟loacl datapath delay。  
吞吐量指的是在单个时钟周期内能够处理的数据量，以每秒比特数来衡量。也就是说，每个时钟周期后能处理多少比特数据。
第二个性能指标是延迟。我们在上一节课中讨论 HLS 时已经提到过这一点。延迟指的是从输入数据开始到得到结果之间的时间。也就是系统为生成结果所需的时间。
下一个性能参数是本地数据路径延迟。它指的是存储单元之间的逻辑延迟，也就是我们用来存储数据的寄存器之间的延迟。
它还决定了最高时钟频率。因为各个存储元件之间的延迟决定了最长的时钟周期。

## 寄存器：降低数据延迟
虽然前面去除寄存器提升了性能，但是我们接下来的优化技术反而叫做“寄存器层”。通过使用这种技术，我们可以缩短局部数据路径的长度，从而提高最高时钟频率。需要知道的是，两个连续逻辑元件之间的连接路径就被称为局部数据路径。而最慢的局部数据路径所导致的延迟，决定了系统的最高时钟频率。通过增加寄存器层，可以减少局部数据路径的延迟。如图所示，第一个示意图中，局部数据路径由一个加法器和一个乘法器组成，因此数据路径的长度为 2 个元件。而在第二个示意图中，数据路径仅由 1 个元件组成。  
但是目前为止我们的延迟都是主观的，不能定量计算。为了量化延迟，我们可以通过寄存器的数量来计算延迟。在第一种方案中，我们可以看到有三个寄存器。在第一个时钟周期，我们将输入值存储在 x1 中；第二个时钟周期，我们将 x1 中的值转移到 x2 中，然后得到最终结果。在这种情况下，延迟为 3 个时钟周期。在第二种方案中，有 4 层寄存器。第一个时钟周期，我们将 x 的值存储在 x1 中；第二个时钟周期，将其存储在 x2 中；第三个时钟周期，我们将中间结果分别存储在 prod1、prod2 和 prod3 寄存器中。  
在第四个时钟周期，我们将计算结果存储到寄存器 Y 中。因此，该方案的延迟时间为 4 个时钟周期。那么，最大时钟频率是多少呢？  
可以看出，方案 A 中的本地数据路径包含两个元件：第一个是加法器，第二个是乘法器。这是从输入到输出的最长路径，也是各寄存器之间的最长连接路径。在这种情况下，如果每个元件的延迟时间为 1 纳秒，那么时钟周期就为 2 纳秒。

最大频率则为 1 除以 2 纳秒，即 500Mhz。不过，在方案 B 中，本地数据路径的长度仅为 1 个单元。由于在两个寄存器层之间只有一个加法器或乘法器，因此时钟周期为 1 纳秒。在这种情况下，最大频率则为 1 除以 1 纳秒，即 1000 Mhz。  


方案 A 的最大频率低于方案 B 的最大频率。不过，方案 A 的延迟则小于方案 B 的延迟。延迟与最大频率并无直接关系。因此，正确答案是“方案 B 能够以更高的时钟频率运行”。如果我们提高方案 B 的时钟频率，虽然可以提高整体性能，但必须注意延迟问题。因为，如果增加额外的寄存器层，就需要更多的时钟周期来获取相同的结果。所以，我们需要找到合适的平衡点。  
## 寄存器平衡；降低数据延迟
在寄存器平衡过程中，会重新分配各寄存器之间的逻辑连接，从而最大限度地减少任意两个寄存器之间的最大延迟。在第一个方案中，本地数据路径包含两个加法器；而在经过寄存器平衡处理后，第二个方案中的本地数据路径则只包含一个加法器。仅仅改动了加法器的位置，就减少了单条数据线路上串联的元件数量，很神奇吧？


## 面积优化
前面的都是为了提高时钟频率和解决延迟而诞生的，但是谁考虑到我们的芯片面积是有限的呢？如果我们面积不足又该如何优化呢？
基本的思路是减少计算单元的数量，同时增加控制逻辑，比如有限状态机逻辑。基于控制的逻辑重用，其实可以与“循环展开”操作相反。流水线结构需要内部数据存储资源以及额外的逻辑来实现并行处理。这些资源可以被重复利用，但代价是处理效率的下降。虽然处理效率会降低，但电路的面积却可以随之减小。而当性能提升时，电路的面积则会上升。这两者是相互矛盾的参数。通常情况下，提升性能的同时，电路的面积会减小。
## 功耗优化
然后你要考虑的就是不让你的芯片变成炸弹：你得考虑功耗（也和发热有关系）：
静态功耗取决于短路电流和漏电流。而动态功耗则与开关电流有关。也就是说，如果某个设备处于开机状态但没有任何操作，那么它只消耗静态功耗。如果该设备正在执行计算任务，那么它就会消耗动态功耗。比如寄存器的值变化，或者正在计算等等。
总功耗是静态功耗与动态功耗的总和。有多种方法可以降低静态功耗或动态功耗。

以上是各种降低功耗的技术。为了降低功耗，可以改进工艺技术，比如减少电容、降低漏电流、降低供电电压。这些都属于物理层面的措施，属于物理技术。不过，我们研究的不是物理技术，而是功能性的技术。我们可以减少开关操作：尽量减少干扰和操作次数。还可以采用低功耗的总线编码方式，以及优化调度和资源分配。此外，还可以使用断电模式：比如时钟关闭、内存分区、电源管理等功能。当然，电压优化和比例调整也是有效的手段。
### 时钟门控
时钟门控是许多同步电路中常用的技术，其目的是为了降低动态功耗。该技术有助于减少数字电路中不必要的能量浪费。在电子产品中，最大的能耗来源就是系统时钟信号。该信号负责控制各个组件的工作状态，而这种状态切换过程会带来额外的能耗。静态功耗其实很小，而动态功耗则很大。因为在计算过程中，有很多元件需要不断切换状态，这就导致了较高的能耗。
实际上，这就是在说因为时钟一直在输出，所以所有原件都在时钟周期内不断尝试刷新状态，这非常消耗能源。解决方法很朴素：使用一个标志来决定是否读取时钟信号，也就是可以对某个模块关闭或开启时钟这样一来，就能减少设计中各部分的切换次数，从而降低这些部分的功耗。
### 数据门控
同样地，我们也可以减少某些算术单元或组合电路的切换次数。比如，那个乘法器：其输入值每个周期都会发生变化，而其输出结果则会被有条件地传送给算术逻辑单元。我们可以利用一些逻辑门来避免不必要的切换操作。例如，我们会使用某些使能信号；如果这些信号处于非激活状态，我们就不会进行任何计算。在幻灯片中，你可以看到低功耗实现方式的示例。
### 内存分块优化

左边那个带 d/q 的方块是个寄存器：15 位的 pre_addr 在时钟上升沿被打进寄存器，输出干净的 addr[14:0]。2¹⁵ = 32K，所以整个地址空间是 32K 个字（每个字 32 位）。
中间把这一个 15 位地址拆开用：低位部分作为每个 bank 内部的字地址，高位部分（图中标的 addr[14:11]，画成接地/判零）用来判断“这个地址是不是落在低地址区间”。
右边是两个 16K × 32 的 RAM bank（2 × 16K = 32K，容量没变）。注意每个 RAM 上都有 noe（输出使能，低电平有效）和 write 信号——每次访问只有一个 bank 被使能，另一个完全不动。
两个 bank 的 32 位输出最后进一个多路选择器（mux），选出被激活那个 bank 的数据作为 dout
通过把大内存分成两小块，我们每次只需要访问其中的一个，大大减少了给内存中的电容充电所需的电力。

通过使用内存分块或分割技术，我们可以减少每次数据访问所需使用的内存容量。如果地址较低，那么就只使用内存块。这样一来，每次数据访问所使用的内存量就会减少，从而降低能耗。因此，内存分块/分割技术既能降低动态能耗，也能降低静态能耗（这里有个接地，后面就会提到这是物理上禁用一个模块的办法）。通过这种方式，我们可以使用更少字长的内存来进行数据访问，从而进一步降低能耗。
### 电源控制
以上都是为了解决动态功耗的。为了降低静态功耗，我们需要在电路上做处理。
我们可以利用睡眠信号或使能信号来控制电路中某些部分的开启与关闭。也就是说，可以通过使能信号或睡眠信号来控制电路的通电与断电状态。这其实是一种开关机制。我们可以将某个逻辑单元与地线相连，或者将其与地线断开。如果将某个逻辑单元与地线断开，那么该单元就会处于睡眠状态。这就是所谓的电源控制。
为了降低功耗，还可以采用不同的电压值。对于那些对速度要求较高的逻辑电路，可以使用较高的供电电压；而对于那些对速度要求不高的逻辑电路，则可以使用较低的供电电压。例如，对于存储器来说，我们可以使用 1.2 伏的电压；而对于逻辑电路，则可以使用 1.0 伏的电压。如果采用不同的电压值，总功耗可以降低 30%。

## HDL中的有限状态机FSM
有限状态机是一种数学抽象模型，它有助于将某种行为表现为一系列状态，以及根据特定事件在这些状态之间切换的过程。
FSM可以简单分为两种状态机：
|  | Moore 机 | Mealy 机 |
| --- | --- | --- |
| 输出取决于 | 仅当前状态 | 当前状态 + 输入 |
| 输出稳定性 | 与状态同步，整个周期稳定 | 输入一变就可能变 |
| 所需状态数 | 多 | 少（更紧凑） |
| 输出实现 | assign y = state | 组合输出逻辑 + 输出寄存器 |
