# 聚类和分类
Classification is the process of dividing objects into pre-defined classes using a set of rules and characteristics determined by humans. 
Classification allows you to create models that can predict how objects will be treated based on certain features. 

Clustering is the process of grouping objects based on their similarities and differences instead of assigning them to pre-defined categories. Clustering allows you to explore unknown and unstructured data, find new groups of objects, and discover hidden patterns. 

The main difference between classification and clustering is that classification requires labeled data for training, while clustering does not use class labels.

Hamming 神经网络（海明网络）——80 年代联想记忆/模式识别的经典网络，是 Hopfield 网络的改进版。基本和前者原理一致但是分类是固定好的

自编码器（Autoencoder, AE）
没有标签，拿输入自己当目标（损失 = ‖x̂ − x‖²）。这叫自监督——上无监督和监督的中间地带。
如果中间层不比输入窄，网络学个恒等映射（W=I）就直接抄近路交差，什么也学不到。

中间层被掐得比输入窄，信息过不去，网络就必须决定“留什么、扔什么”——留下的就是数据最本质的特征（code/编码）。
