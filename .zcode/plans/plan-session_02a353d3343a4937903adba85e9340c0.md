## 目标

给文章加"形式主义口令锁"：挡住点开链接的无心人、搜索引擎快照、RSS 订阅器。不做真加密（正文明文仍在 HTML 源码和公开仓库里，这是已确认的边界）。

## 机制约定

文章 front matter 加任一字段即视为"已上锁"：
- `password: "口令"` —— 最简用法；
- `password_sha: "<sha256 hex>"` —— 口令本身不落明文（防止口令复用泄露），实现时可用 `echo -n 口令 | sha256sum` 生成。

## 文件改动（4 个文件）

**1. `_layouts/post.html`**（核心）
- 内容区改为条件渲染：有锁标记时，渲染一个构成主义风格的锁屏卡片（黑底、`--sov-red` 橙红强调、大写"此篇已上锁"、口令输入框 + 解锁按钮、硬边框+硬阴影，样式自包含在条件块内的小段 `<style>` 里），正文放在 `hidden` 的 div 里；无锁标记则一切照旧。
- 解锁脚本：输入经 WebCrypto SHA-256 后与 `password_sha` 比较（`password` 字段则直接比较）；成功显示正文并写入 `sessionStorage[location.pathname]`，本次会话刷新不再要口令；失败抖动+提示。
- Gitalk 块外加 `{% unless %}`：锁文不挂评论，避免公开 GitHub issue 暴露文章存在。

**2. `feed.xml`**：item 循环加 `{% unless post.password or post.password_sha %}` —— 锁文不进 RSS（否则全文输出，白锁）。

**3. `index.html`**：首页对锁文把前 200 字摘要（`post.content | strip_html | truncate:200`，第 18 行）替换为固定文案"🔒 此篇已上锁，钥匙在博主手里。"，标题后追加 🔒。

**4. `tags.html`**：锁文标题后追加 🔒（该页只列标题，无摘要泄露）。

## 验证

- 探测本地 `jekyll`：可用则 `jekyll serve`，临时建一篇带 password 的测试文章（验证完删除，不提交），检查锁屏渲染/解锁/刷新免输/错误提示、首页摘要替换、tags 🔒、feed.xml 不含该文。
- 本地无 jekyll 则静态核对 Liquid 语法，推送后由 GitHub Pages 构建，你在真站点开验证（我不主动 commit/push）。

## 用法（交付后）

给任意文章 front matter 加 `password: "口令"` 即自动生效：锁屏 + 列表 🔒 + 退出 RSS + 关评论。已发布的历史文章不在保护范围（明文在 git 历史里永久存在）。About Blog 介绍页不在本次范围。
